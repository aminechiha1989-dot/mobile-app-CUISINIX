# Écrans du MVP

## 1. Accueil
- Bouton principal : photographier les aliments.
- Option secondaire : saisir les ingrédients à la main.
- Accès aux favoris.

## 2. Confirmation des ingrédients
- Liste des ingrédients détectés sous forme de puces.
- Supprimer une puce ; ajouter un ingrédient avec recherche.
- Bouton « Continuer ». L'écran doit être rapide : c'est le point qui décide si l'utilisateur reste.

## 3. Filtres
- Repas : petit-déjeuner, déjeuner, dîner.
- Budget en DT, avec l'option « 0 DT » (uniquement ce que l'on possède).
- Cuisine : tunisienne, italienne, française, marocaine, turque, indienne, mexicaine...

## 4. Liste de recettes
- Carte par recette : nom, temps de préparation, nombre d'ingrédients manquants, coût estimé.
- Tri par meilleur taux de correspondance.
- Message clair si aucune recette ne correspond (proposer d'augmenter le budget).

## 5. Détail de la recette
- Ingrédients disponibles et manquants, distingués visuellement.
- Coût estimé (affiché comme « estimation »).
- Étapes de préparation.
- Bouton favori (invite à créer un compte si besoin).

## Navigation

Accueil → Confirmation → Filtres → Liste → Détail, avec retour possible à chaque étape.
